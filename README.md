# 🎮 CLI Game in C# – OOP Edition

A fully interactive **command-line game** built in **C#**, showcasing the power of **Object-Oriented Programming**.  
This project was designed to reinforce key OOP concepts like encapsulation, inheritance, polymorphism, and abstraction through a fun and engaging terminal-based game.
